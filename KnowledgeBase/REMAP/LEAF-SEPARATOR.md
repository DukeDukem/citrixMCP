## How to use

1. Finish leaf A (breadcrumb + body + screenshots).
2. Paste the 5-line block above.
3. Paste leaf B (its Sabio breadcrumb first, then body).

## Agent recognition rule

Any line containing the exact token **`KB-LEAF-SEPARATOR`** marks a hard boundary between two leaves. Content above = previous leaf; content below = next leaf.

## Optional Word styling

- Font: Consolas or Courier New, size 12–14  
- Bold: entire block  
- Color: dark red or dark blue (optional; not required)
