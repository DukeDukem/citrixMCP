# REMAP exports

Drop captured Sabio articles here (`.md` preferred; `.docx` / `.pdf` OK).

```
exports/
  process/rechnung-zahlung|vertrag|hardware|self-service|technik|ausland|tarife|vermarktung|optionen/
  systems/telefonica-prozesse|telefonica-systeme/
```

**Naming:** `{slug}__{YYYY-MM-DD}.md` (or `.docx`)

**Markdown header (recommended):**
```markdown
# <Article title>
- Breadcrumb: `L1 > L2 > …`
- Themen-ID:
- System:
- Tag: HANDLE | TRANSFER_ONLY | HOTLINE_REFER
- Captured: YYYY-MM-DD
```

Then set checklist Status → `captured`.
