Grundsätzlich gilt: o2 stellt keinen eigenen Anrufbeantworter direkt im Festnetz bereit. Wenn bei Ihnen zuhause Nachrichten auf einem Anrufbeantworter landen, stammen diese in der Regel von Ihrem Router (z. B. FRITZ!Box) oder von einem Telefon mit eingebautem Anrufbeantworter.

Fernabfrage auf den Festnetz-Anrufbeantworter (z. B. im Urlaub):
- Rufen Sie Ihre Festnetznummer an.
- Sobald die Ansage startet, drücken Sie die Sterntaste (*).
- Geben Sie die PIN ein, die Sie in den Telefonie-Einstellungen Ihres Routers bzw. Geräts für die Fernabfrage festgelegt haben.
- Bei einer FRITZ!Box finden Sie die Einstellung unter: Telefonie → Anrufbeantworter → Einstellungen → „Fernabfrage aktiv“.

Das ist unabhängig von der früheren E-Plus/BASE-Prepaid-Funktion und hängt von Ihrem Gerät zuhause ab.

Falls Sie Ihre mobile o2-Mailbox meinen (Anrufbeantworter auf dem Handy):
- Vom eigenen o2-Handy: Kurzwahl 333.
- Von einem anderen Anschluss oder im Ausland: Ihre Mailbox-Rufnummer im internationalen Format wählen (bei 0178 … mit Mailbox-Infix 99), Ansage mit * unterbrechen, Mailbox-PIN eingeben und mit # bestätigen.
- Übersicht und weitere Hinweise: https://www.o2online.de/service/mailbox-voicemail/
